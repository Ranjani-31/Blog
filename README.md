# Blog
## 📝 Blog Website
### 1. Overview

This is a simple and modern blog website where users can read, create, and manage blog posts.
The goal of this project is to provide a clean reading experience and help beginners understand how a real-world blog platform works.

### 2. Features

- Read and browse blog posts

- Create, edit, and delete blogs

- User authentication (login & signup)

- Categories and tags

- Responsive design for all devices

### 3. Tech Stack

F### rontend:

- HTML

- CSS

- JavaScript

- React.js

### Backend:

- Node.js

- Express.js

### Database:

- MongoDB

### 4. Installation

**Clone the repository**

    git clone https://github.com/your-username/blog-website.git


**Install backend dependencies**

    cd server
    npm install
    npm run dev


**Install frontend dependencies**
    
    cd client
    npm install
    npm run dev
